# 珠宝小红书账号运营复盘表 — 工具表结构

> 来源：腾讯文档附件《泉泉珠宝获客丨珠宝小红书账号运营复盘表.xls》（21.0 KB）
> 说明：原表为空白模板（无数据），已按预览结构重建为同名 .xlsx 文件（含 Sheet1/2/3）。本 MD 记录其结构，便于查阅与复用。

## 用途

对账号的笔记数据与一周运营数据进行系统复盘，找出内容好坏、形成标准化内容生产 SOP（文档正文强调：多数珠宝老板缺的正是作品复盘总结）。

## 工作表结构

每个 Sheet 为一份独立复盘表（Sheet1/Sheet2/Sheet3），结构相同，可分别按周/月使用。

## 行结构（三大板块）

### 板块一：单篇笔记数据

| 字段 | 说明 |
|---|---|
| 发布时间 | 笔记发布时间 |
| 主题 | 笔记主题 |
| 创作内容 | 创作方向与内容 |
| 浏览量 | 曝光数据 |
| 点赞 | 点赞数 |
| 收藏 | 收藏数 |
| 评论 | 评论数 |
| 涨粉量 | 新增粉丝 |
| 分享数 | 分享次数 |
| 主要观众来源 | 流量来源（推荐/关注/搜索） |

### 板块二：一周数据汇总

| 字段 | 说明 |
|---|---|
| 新增粉丝 | 周涨粉 |
| 主要访客 | 访客特征 |
| 浏览量 | 周总曝光 |
| 浏览时长 | 平均浏览时长 |
| 互动数 | 总互动量 |
| 点赞 / 收藏 / 评论 | 互动明细 |
| 弹幕 | 直播弹幕数 |
| 分享 | 分享数 |

### 板块三：周总结

单独一行用于记录本周复盘结论与下周优化方向。
