# 珠宝小红书直播对标账号数据监控分析表 — 工具表结构

> 来源：腾讯文档附件《泉泉珠宝获客丨珠宝小红书直播对标账号数据监控分析表.xls》（20.5 KB）
> 说明：原表为空白模板（无数据），已按预览结构重建为同名 .xlsx 文件（含 Sheet1/2/3）。本 MD 记录其结构，便于查阅与复用。

## 用途

监控对标账号的直播数据（GMV、人气、客单价、UV 价值等），用于评估直播带货效果、制定自身直播策略。

## 工作表结构

每个 Sheet 为一份独立监控表（Sheet1/Sheet2/Sheet3），结构相同。

## 列结构

| 列 | 字段 | 说明 |
|---|---|---|
| A | 账号 | 对标账号 |
| B | 直播时间 | 直播日期/时段 |
| C | GMV | 成交总额 |
| D | 人气峰值 | 最高在线人数 |
| E | 客单价 | 平均客单价 |
| F | 总场观看人数 & UV 价值 | 场观人数与人均价值 |
| G | 销量 | 成交件数 |
| H | 直播时长 | 直播时长 |

## 使用建议

- 定期（如每周）记录对标账号直播数据，横向对比转化效率
- 结合客单价与 UV 价值判断账号的流量质量与变现能力
