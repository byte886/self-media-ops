# 珠宝小红书对标账号拆解表 — 工具表结构

> 来源：腾讯文档附件《泉泉珠宝获客丨珠宝小红书对标账号拆解表.xlsx》（11.79 KB）
> 说明：原表为空白模板（无数据），已按预览结构重建为同名 .xlsx 文件（含 Sheet1/2/3）。本 MD 记录其结构，便于查阅与复用。

## 用途

横向拆解 9 个对标账号的定位、选题、爆款笔记与数据表现，用于账号定位与内容策略参考。

## 工作表结构

每个 Sheet 为一份独立拆解表（Sheet1/Sheet2/Sheet3），结构相同，可分别存放不同细分赛道（如回收/售卖/定制）的对标账号。

## 行结构（拆解维度）

| 分组 | 拆解项 | 说明 |
|---|---|---|
| **账号定位** | 名称 | 账号昵称 |
| | 简介 | 账号简介文案 |
| | 粉丝数 | 粉丝规模 |
| | 人设定位 | 人设类型（鉴定师/买手/老板等） |
| | 账号特色 | 差异化特色 |
| **选题内容** | 选题方向 | 内容赛道与主题 |
| | 内容类型 | 图文/视频/直播等 |
| | 话题 | 常用话题标签 |
| | 关键词 | 布局关键词 |
| | 笔记数量 | 发布量 |
| | 更新频率 | 更新节奏 |
| | 发布时间 | 发布时段 |
| **爆款笔记** | 标题 | 爆款标题 |
| | 封面 | 封面样式 |
| | 文案 | 文案结构 |
| | 内容结构 | 视频/图文结构 |
| **笔记数据** | 点赞数 | 平均点赞 |
| | 收藏数 | 平均收藏 |
| | 评论数 | 平均评论 |

## 列结构

| 列 | 字段 |
|---|---|
| A | 筛选方向（分组标签） |
| B | 拆解项 |
| C-K | 账号1 ~ 账号9（每个账号一列） |
