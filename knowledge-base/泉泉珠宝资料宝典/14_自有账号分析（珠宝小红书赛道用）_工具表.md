# 自有账号分析（珠宝小红书赛道用）— 工具表结构

> 来源：腾讯文档附件《泉泉珠宝获客丨自有账号分析（珠宝小红书赛道用）.xls》（26.0 KB）
> 说明：原表为空白模板（无数据），已按预览结构重建为同名 .xlsx 文件（含 Sheet1/2/3）。本 MD 记录其结构，便于查阅与复用。

## 用途

记录自有账号发布内容的选题、目的与数据，用于内容规划与效果评估，是内容生产 SOP 的落点工具。

## 工作表结构

每个 Sheet 为一份独立分析表（Sheet1/Sheet2/Sheet3），结构相同。

## 列结构

| 列 | 字段 | 说明 |
|---|---|---|
| A | 发布日期 | 笔记发布日期 |
| B | 标题 | 笔记标题 |
| C | 文案 | 笔记文案 |
| D | 选题 | 选题方向 |
| E | 内容 | 内容形式/要点 |
| F | 目的（引流种草/吸粉） | 内容目的分类 |
| G | 数据 | 互动/转化数据 |
| H | 备注 | 复盘备注 |

## 使用建议

- 每篇笔记发布后回填数据，按"目的"维度复盘内容效果
- 与运营复盘表联动，形成"选题→发布→数据→复盘→优化"的完整 SOP
