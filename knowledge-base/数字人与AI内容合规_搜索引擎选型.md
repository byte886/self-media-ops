# 数字人/AI内容合规规则（2026-10-07）

## 短视频 vs 直播的实名边界

| 场景 | 要求 |
|------|------|
| 纯短视频（不直播） | 账号基础实名 + AI标签即可，不需要虚拟主播实名注册 |
| 直播/带货 | 须虚拟主播实名注册 + 平台审核 |
| 挂车带货 | 标AI + 实物图 + 类目准入（珠宝需报白） |

## 珠宝类目特殊要求
- 短视频带货需报白/定向准入
- 数字人不能豁免类目准入
- 商品图必须实物图，不能用AI生成的珠宝图冒充实物

## 不标注AI的后果
- 首次：扣健康分
- 二次：限挂车3天
- 三次：关橱窗7天，限流下架

## 实操建议
- 珠宝知识科普号（不带货）：数字人放心用，勾AI标签
- 自家产品展示：真人出镜，或数字人走"实名+AI标识+实物图"路径
- 最稳组合：真人口播做自家货，数字人做泛知识

# 搜索引擎选型（2026-10-07）

## 推荐使用
| 搜索引擎 | 用途 |
|----------|------|
| Google | 主力搜索 |
| Bing | 补充，微软生态 |
| DuckDuckGo | 隐私保护，不追踪 |
| Brave | 独立索引，速度快 |
| Startpage | 隐私保护，Google结果 |

## 不推荐
- 百度：质量不好，广告多

## 组合调研方法
1. 先用AI问一遍
2. 根据AI回答的线索，去Google/Bing搜
3. 交叉验证，不要只信一个来源
4. 小众问题用DuckDuckGo/Brave补充
