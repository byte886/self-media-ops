# D1：老板自我介绍（2026-10-08）

## 视频号版（45-60秒）
**标题：** 我是老X，在襄阳开了两家翡翠店

**口播：**
"很多人问我，你在襄阳做翡翠做了多少年了？
其实算下来有十多年了。
为什么在襄阳开两家店？
因为我觉得翡翠这个东西，必须要当面看、上手摸，照片拍不出来那种感觉。
我这家店不做美颜滤镜，不做仙图。
你来了，我拿自然光给你看，喜欢再谈价格。
我是老X，襄阳两家翡翠实体店，欢迎来喝茶。"

## 抖音版（15-40秒）
**标题：** 在襄阳开了两家翡翠店的老板

**开头3秒：** "襄阳买翡翠的朋友，先别划走。"

**内容：** 同上，精简到30秒。

## 小红书版（图文）
**标题：** 在襄阳开了两家翡翠店｜买翡翠不踩坑

**图片：**
1. 店面门头
2. 柜台全景
3. 自然光下的手镯特写

**正文：**
"做翡翠十多年了，在襄阳开了两家实体店。
为什么不做线上套路？
因为翡翠必须上手看，照片拍不出来。
来店里，自然光看货，喜欢再谈。
襄阳的朋友，欢迎来喝茶。"

## 拍摄要求
- 手机竖拍
- 自然光下拍
- 不用美颜
- 老板出镜，自然说话
