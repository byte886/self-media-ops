# 运营策略总纲（SYSTEM STRATEGY）

> **文档类型**：Governance（方向层）
> **维护者**：人拍板，AI执行
> **定位**：管"做什么、优先级"；系统怎么转见 `content-pipeline/docs/SYSTEM_ARCHITECTURE.md`

---

## 我们在五仓体系里的位置

```
①采集底座 → ②调研方法 → ③情报雷达 → ④生产执行 → ⑤运营分发（我们在这）
```

我们负责：拿到选题和素材后，写成文案、排好发布计划、过质量检查、发出去。
不负责：采集数据、出图出视频（那是④的事）、监控情报（那是③的事）。

---

## 当前项目：珠宝冷启动（2026-10起）

**只做这一件事。** 其他项目以后再说。

| 项 | 内容 |
|---|------|
| 业务 | 襄阳两家翡翠实体店，帮店主做线上获客 |
| 人设 | 10年翡翠店老板，接地气说真话，不出镜 |
| 平台优先级 | 视频号 > 小红书 > 抖音 |
| 目标 | 公域内容 → 私信咨询 → 加微信 → 私域成交 |
| 不做 | 不投流、不开店、不发赌石、不留微信号在内容里 |

### 内容线区分
- **珠宝线**（本项目）：翡翠知识+产品+日常，发视频号/小红书/抖音
- **朋友圈线**（另一个项目）：AI行业观察，发朋友圈，和珠宝无关
- 两条线人设不同，不混
