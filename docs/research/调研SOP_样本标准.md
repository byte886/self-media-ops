# 珠宝自媒体竞品调研 SOP

> 每次做平台调研时按这个标准执行，不要凭感觉采样。

## 正确流程（所有平台通用）

1. **搜关键词 → 找高赞内容（视频/笔记）**
2. **点进爆款内容 → 看创作者是谁**
3. **进创作者主页 → 筛选是否合格对标**

> 注意：不是直接搜"账号"tab！先找爆款内容，再反查账号。

## 各平台操作差异

| 平台 | 搜索入口 | 爆款判断 | 备注 |
|------|----------|----------|------|
| 小红书 | 搜索关键词→笔记tab | 点赞收藏高的笔记 | 注意账号被风控，别用自动化翻收藏 |
| 抖音 | 搜索关键词→视频tab | 点赞过万/小众过千 | 按"最多点赞"排序 |
| 视频号 | 搜索关键词→账号/视频 | 不显示粉丝数，看视频点赞 | 企业蓝V为主，佛山商家多 |
| YouTube | 搜索关键词→Filters→View count | 播放量排序 | 需VPN |
| TikTok | 搜索关键词→按点赞排序 | 需VPN |
| Instagram | 搜索hashtag→Top posts | 需VPN |

## 合格对标账号标准

- 近半年内起号
- 粉丝1-10万（不是大V，大V打法学不来）
- 近期有爆款（小众赛道几千赞就算爆款）
- 一部手机能拍的，不是专业团队/大商家
- 变现路径清晰
- 比自己大1-5倍即可，不要找超大号

## 样本量标准

- **每个平台采集 8-12 个合格对标账号**
- 覆盖三类：直接竞品（同行同类型小店）、相邻竞品（不同品类但同客群）、愿景对标（想成为的样子）
- 每个账号采集最近 3 个月的内容

## 每个账号要采集的数据

| 数据项 | 说明 |
|--------|------|
| 账号名 | 全名 |
| 地区 | 城市/产地 |
| 认证类型 | 企业蓝V/个人认证/无认证 |
| 粉丝数 | 能看到就记（视频号不显示就标"不公开"） |
| 视频/笔记总数 | 累计内容量 |
| 更新频率 | 最近一条距今天数 |
| 内容类型分布 | 产品展示/知识科普/创业vlog/鉴宝/直播切片各占比 |
| 爆款数据 | 点赞最高的3条视频的点赞数和选题 |
| 引流方式 | 简介/置顶/评论区怎么引导加微信 |
| 人设标签 | 店主/鉴定师/买手/宝妈/源头商家 |

## 采集工具

- **小红书/抖音/视频号**：外部Chrome（CDP连接）或手机adb控制
- **海外平台**：YouTube/TikTok/Instagram/Twitter，需VPN
- **AI交叉验证**：DeepSeek/豆包/元宝（国内）+ Claude/ChatGPT/Gemini/Grok（海外）
- **Google搜索**：方法论、行业benchmark

## 验收标准

- 每个平台至少8个合格对标账号（不是凑数的大商家）
- 能总结出"什么内容在这个平台能起来"
- 能总结出"小号冷启动应该怎么做"
- 数据来源标注清楚，不编造
