# 琛盛堂翡翠 30天冷启动执行手册（综合版 2026-10-07）

## 数据来源
- 店主自己的30天方案
- Claude/ChatGPT/DeepSeek等6个AI调研
- Google 30+篇资料
- 实地调研小红书9个账号+抖音6个账号+视频号10个账号

## 核心定位
- 账号名：琛盛堂翡翠
- 人设：襄阳实体店老板，12年经验，敢说真话
- 目标：内容→流量→私信→微信→到店/成交

## 三平台分工

| 平台 | 角色 | 优先级 |
|------|------|--------|
| 视频号 | 主战场：老客复购+转介绍 | 第一 |
| 小红书 | 种草搜索：拉新客 | 第二 |
| 抖音 | 同城获客 | 第三 |

**为什么视频号第一：** 你有微信私域客户，视频号是唯一能把老客激活的渠道。

## 内容生产方式
**一次拍摄，三版剪辑：**
- 每周集中拍一次（2-3小时）
- 产出：1条主视频 + 8-10张照片
- 剪成三个版本发三个平台

## 30天计划（综合店主方案+AI调研）

### 阶段1：基础设施（Day 1-3）
**目标：** 账号、商品库、拍摄环境就绪

| 天 | 任务 |
|---|------|
| D1 | 确定账号名"琛盛堂翡翠"，选20件商品（翡翠5、珍珠4、和田玉4、彩宝4、文玩3），选5件重点商品，定拍摄位置 |
| D2 | 5件重点商品×每件10张照片+5段视频=50张照片、25段视频 |
| D3 | 建立内容模板：为什么贵、价格合理吗、小白踩什么坑、同行为什么差10倍、老板怎么买 |

### 阶段2：高强度测试（Day 4-10）
**目标：** 18-30条内容，找出有效题材

| 天 | 任务 |
|---|------|
| D4 | 发3条：老板IP、知识型、商品型 |
| D5 | 发3条，回复所有评论，记录数据 |
| D6 | 发3条，测试价格型：1000/3000/5000预算怎么买 |
| D7 | 第一次数据复盘：找出表现最好的5条 |
| D8-10 | 哪个题材有效就连续复制，每天3-4条 |

### 阶段3：成交验证（Day 11-20）
**目标：** 跑通私信→微信→到店

| 天 | 任务 |
|---|------|
| D11-14 | 建立私信承接：先问预算和喜欢的类型，不要直接问加微信 |
| D14 | 复盘：流量最高10条、收藏最高10条、私信最高10条 |
| D15-18 | 垂直内容：翡翠为主，测试哪个方向最出客户 |
| D19 | 第一次30-60分钟直播：《今晚给大家看10件店里的真实珠宝》 |
| D20 | 真实顾客购买场景：预算5000为什么推荐这类 |

### 阶段4：放大复制（Day 21-30）
**目标：** 找到有效模型，SOP化

| 天 | 任务 |
|---|------|
| D21-23 | 选3件最有潜力商品，每件做10条内容 |
| D24-25 | AI流水线：老板负责商品+真人，AI负责选题+脚本+文案 |
| D26 | 选5件不同价格带商品，连续做5条内容 |
| D27 | 回访10个老客户，问"如果重新买最担心什么" |
| D28-30 | 最终复盘，写出SOP |

## 三平台改编方式

**视频号：**
- 时长1-3分钟，老板出镜，像讲给熟人听
- 发布后转发朋友圈+客户群

**小红书：**
- 图文6-9张，首图带文字标题
- 标题带关键词："翡翠手镯""预算""避坑"
- 自然光真实上手图

**抖音：**
- 15-40秒，前3秒强钩子
- 每条加襄阳定位

## 每天工作清单
- 找1-3个真实客户问题
- 写/生成脚本
- 拍摄1-4条
- 剪辑并发布
- 回复评论和私信
- 记录当天数据

## 30天KPI
- 内容发布：70-90条
- 直播：2-3场
- 新增微信：目标自定
- 到店客户：目标自定

## 红线
- 不说"保值升值投资"
- 不留微信号在视频里
- 不卖赌石
- 象牙不出现
- 不贬低同行
