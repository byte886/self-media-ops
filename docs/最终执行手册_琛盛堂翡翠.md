## 二、怎么赚钱

**路径：内容 → 吸引关注 → 私信咨询 → 加微信 → 私域成交 → 复购转介绍**

- ❌ 不开小红书店铺、不开抖音小店、不做独立站、不上淘宝
- ✅ 所有成交在微信上完成
- ✅ 新客首单走闲鱼验货宝担保（建立信任），复购老客直接微信转账

## 四、加微信的正确姿势

**视频号（最顺）：**
- 用户看视频 → 点头像进主页 → 点企业微信按钮 → 直接加你
- 不需要你说任何话

**小红书/抖音（等用户主动）：**
- 笔记/视频里不提微信、不说"私信我"
- 用户看完感兴趣 → 评论区问"怎么买" → 你回复"看主页"或私信聊
- 私信里也不直接甩微信号，等对方问联系方式再给
- 硬甩微信号 = 封号红线

**新客信任建立（六层）：**
1. NGTC国检证书随货发
2. 按客户要求拍专属看货视频（自然光+打灯看裂+量尺寸）
3. 鉴赏期条款文字确认（收到货7天不满意可退）
4. 新客首单走闲鱼验货宝担保交易
5. 朋友圈老客见证截图
6. 实体店出镜兜底（拍店面、拍柜台）
