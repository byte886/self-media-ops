# ADR-004：不出镜不录音的内容形式

> **状态**：已确认
> **日期**：2026-10-08

## 决策

**不真人出镜，不AI配音，用以下形式：**

| 平台 | 形式 |
|------|------|
| 小红书 | 产品实拍图+知识卡片轮播（图文） |
| 视频号 | 手持产品窗边自然光拍摄，纯音乐+硬字幕 |
| 抖音 | 手持产品对光拍摄，纯音乐+硬字幕，25-45秒 |

**不用：**
- ❌ AI数字人口播（抖音严管，容易被判营销号）
- ❌ AI配音（要双重标注，且听着机器）
- ❌ 真人出镜（操作者不想，店主没时间）

## 为什么

- 调研结论：国内跑通的珠宝号没有一个是纯AI生成做起来的
- "手持镯子对窗光照一下"是翡翠圈成熟形式，不拍脸不说话完全可行
- 抖音"我满脑子都是司凤"51.2万粉证明了不露脸能跑
- AI用来写文案初稿、做封面、出标题，不用来生成视频画面

## 拍摄要求

- 手机竖拍，4K
- 自然光下（窗边最好）
- 只拍手和产品
- 每个产品拍3个镜头：整体转一圈、手电打灯看内部、戴手腕效果
- 一次拍5-8个产品够一周发

## 风险

- 纯产品图路线（像"聪丽遇翠"）已验证是死路，必须加知识和人设
- 我们的差异化：产品实拍+知识卡片+老板语气，不是纯发图
