# ADR-003：珠宝项目人设与朋友圈线区分

> **状态**：已确认
> **日期**：2026-10-08

## 决策

珠宝项目人设为**襄阳翡翠店老板，接地气说真话**：
- 不装专家，不说"我教你"
- 不端着，有情绪（惊讶、心疼、得意、无奈）
- 说"我干了10年见过太多人花冤枉话"
- 不说"私信我/扣1"
- 不完美，"我也看走眼过"

**与朋友圈线的区别：**
| | 珠宝线 | 朋友圈线 |
|---|--------|---------|
| 人设 | 翡翠店老板 | 边学边分享的积极派博主 |
| 语气 | 专业但说人话 | 分享观点有情绪 |
| 内容 | 翡翠知识+产品+日常 | AI行业观察 |
| 是否提珠宝 | 是 | 否 |

## 为什么

- 两条线受众不同：珠宝线客户要信任你是懂行的；朋友圈线朋友要觉得你有意思
- 珠宝线需要专业背书（10年实体店），朋友圈线需要真诚感
- 混在一起会两边都不讨好

## 反例（禁止出现）

- ❌ 珠宝内容里说"家人们谁懂啊"
- ❌ 朋友圈内容里提翡翠店
- ❌ 珠宝内容用"赋能/闭环/打法"
