# 每日脚本模板

> **文档类型**：Template（脚本模板）
> **用法**：每天写脚本时复制这个模板，填内容

---

## 视频号（60-90秒）

```
【标题】（一句话说清这条视频讲什么，带情绪）

【画面】
[0-3秒] 什么画面（产品特写/柜台/手拿起）
[3-15秒] 什么画面
[15-40秒] 语音/字幕内容
[40-60秒] 什么画面
[60-90秒] 结尾画面

【语音/字幕】（写在这里）
（口语化，不要书面语，至少2个"我"，至少1个具体数字）

【描述文字】
（3-5行，和视频内容呼应，不要重复）

【标签】#襄阳翡翠 #翡翠手镯 #实体店 #（根据内容加）
```

---

## 小红书（图文6-9张）

```
【标题】（从200个爆款标题参考改写，埋关键词：翡翠手镯/避坑/襄阳）

【正文】
（开头2行抓人，然后分点说干货，结尾个人感受）

【图片规划】
第1张（封面）：产品图 + 大字标题
第2张：知识点1
第3张：知识点2
第4张：产品细节图
第5张：知识点3
第6张：总结/个人感受

【标签】#翡翠手镯 #翡翠 #翡翠避坑 #珠宝 #襄阳
```

---

## 抖音（25-45秒）

```
【标题】（前3秒文字钩子）

【画面】
[0-3秒] 前3秒文字："（一句话钩子，比如：襄阳买翡翠的朋友先别划走）"
[3-15秒] 产品特写，手拿起
[15-30秒] 字幕内容（一个知识点）
[30-45秒] 结尾：产品自然光转动

【字幕内容】（一个知识点，不要贪多）
（纯音乐，不配音）

【描述】
（2-3行，简短）

【标签】#襄阳翡翠 #翡翠手镯 #襄阳探店
【定位】襄阳
```

---

## 每天必填的参考对象

```
【参考模仿对象】
- 账号名：
- 具体哪条笔记/视频：（标题或链接）
- 学它什么：（开头钩子/内容结构/标题写法）
- 我们改了什么：（不是照搬，要改成襄阳/我们的产品）
```
