# 珠宝自媒体冷启动 · 需求与调研规范

> 创建：2026-10-07
> 状态：进行中
> 维护人：魏强团队

---

## 一、背景

- 襄阳两家实体店（翡翠/宝石为主），营业执照：湖北琛盛堂文化传媒有限责任公司
- 帮朋友做宣传，不是店主本人出镜
- 不出镜、不录音（结巴）
- 已有供应商产品素材（蓝宝石戒指等样品视频）
- 朋友圈AI行业观察系列是另一条线，和珠宝完全分开

## 二、调研目的

1. 找小而美、能持续输出的珠宝店案例（不是突然爆火又掉下去的大V）
2. 搞清楚不出镜、不录音的情况下怎么做内容能起量
3. 验证哪些内容形式真的能引流到私域成交
4. 搞清楚平台红线（什么会被限流/封号）
5. 形成一套可执行的SOP

## 三、调研要求

### 3.1 渠道清单

| 类别 | 渠道 |
|------|------|
| 搜索引擎 | Google（高级操作符）、百度 |
| 国内平台直接刷 | 小红书、抖音、视频号、B站 |
| 海外平台 | YouTube、TikTok、Instagram、Twitter（用VPN） |
| 海外AI交叉验证 | Claude、ChatGPT、Gemini、Grok |
| 国内AI交叉验证 | DeepSeek、豆包、腾讯元宝 |
| 已有情报库 | self-media-ops仓库、生财有术珠宝帖综合情报 |

### 3.2 调研方法

- 真去刷平台看账号数据（粉丝数、获赞、内容形式），不是只做网页搜索
- 找的是"小店主"案例，不是大博主、大品牌
- 同一个结论至少两个来源确认（三角验证）
- 样本量要够，几十个账号都可以
- 调研完记录用了哪些渠道、每个渠道找到了什么

### 3.3 样本标准

- 粉丝数在500-5000之间的小号优先
- 经营时间3个月以上，不是爆一波就消失
- 有真实出单/成交记录的优先
- 不出镜/不说话的账号优先（因为我们也是这样）

## 四、最终产出

1. **账号定位**：人设、简介方向、头像风格
2. **内容排期**：每天发什么、什么形式（图文/视频）
3. **配图/视频方案**：不拍脸不说话怎么拍
4. **引流方法**：怎么合规地把人引导到微信
5. **三平台各自SOP**：小红书、抖音、视频号分别怎么做
6. **执行手册**：什么时候开始、第一条发什么、每天怎么操作

## 五、明确不要的

- 不要纯产品图（已验证死路）
- 不要"扣1私信"等钩子话术
- 象牙/文玩核桃不进公域
- 不开在线购物平台/小店
- 不要AI味太重的文案
- 不要留微信号/二维码在公域内容里
