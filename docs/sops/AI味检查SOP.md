# AI味检查SOP

> 类型：How-to（质检流程）
> 每次发布前必须执行

## 检查清单

### 一读：像人说的吗？
- [ ] 大声读出来，有没有卡顿/书面感
- [ ] 有没有"首先/其次/最后/总之/综上所述/值得注意的是"
- [ ] 有没有"在这个...的时代""随着...的发展"

### 二查：有个人味道吗？
- [ ] 有"我"字吗（至少出现2次）
- [ ] 有语气词吗（"挺""真的""居然""说实话"）
- [ ] 有具体的个人感受，不是纯转述

### 三看：有干货吗？
- [ ] 至少一个具体数字
- [ ] 至少一个具体案例/人名
- [ ] 不是空泛的道理

### 四排：有营销味吗？
- [ ] 没有"扣1/私信/领取/关注我"
- [ ] 没有"转发给需要的朋友"
- [ ] 结尾不是行动号召，是个人感受

## 不合格怎么改

| 问题 | 改法 |
|------|------|
| 太书面 | 加语气词，把长句拆成短句 |
| 太干 | 加一个"我当时看到这个数字愣了一下" |
| 太营销 | 删掉最后一句行动号召，换成个人感受 |
| 太短 | 补一个案例或数据细节 |
