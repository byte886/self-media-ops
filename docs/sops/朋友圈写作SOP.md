# 朋友圈写作SOP

> 类型：How-to（操作指南）
> 适用：把一篇长文转化为朋友圈系列内容

## 步骤

### 1. 拆原文
- 找出主论点（3-7个）
- 每个论点单独成一条朋友圈
- 保留原文的数据、案例、情绪金句

### 2. 改写
- 开头用"我刚看到一个观点，挺震撼的"或类似个人语气
- 中间铺陈论点+数据+案例
- 结尾留一句个人感受，不要行动号召
- 字数控制在200-400字（厚实但不冗长）

### 3. 配图
- 黑底白字字卡（核心数字/金句）
- 一条朋友圈最多配3张图
- 字卡不要超过15字/张

### 4. 质检（发布前必过）
- [ ] 读一遍像人说的话，不是AI写的说明文
- [ ] 没有"首先/其次/最后/综上所述"
- [ ] 没有"扣1/私信我/领取"
- [ ] 有至少一个具体数字或案例
- [ ] 有个人语气词（"挺""真的""我"）
- [ ] 配图黑底字卡已生成

## 常见错误

- 太薄：一行字+一张图，看一眼就划走
- 太AI：通篇书面语，没有个人情绪
- 顺序反：先讲案例再讲主论点
