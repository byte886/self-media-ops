# 琛盛堂翡翠 自媒体冷启动执行手册

## 一、调研方法与渠道

### 1.1 调研渠道
| 渠道 | 具体做了什么 | 数量 |
|------|-------------|------|
| Google搜索 | 搜索"视频号翡翠运营""小红书珠宝获客""抖音同城翡翠店"等关键词 | 3轮，30+篇文章 |
| 实地刷平台 | 小红书搜"翡翠手镯 避坑"，看9个账号 | 9个对标账号 |
| 实地刷平台 | 抖音搜"小县城玉镯店"，看6个账号 | 6个对标账号 |
| 实地刷平台 | 视频号用adb控制手机刷，看10个账号 | 10个对标账号 |
| AI交叉验证 | 问6个AI同一个问题：视频号要不要做？ | 6个AI |

### 1.2 6个AI分别给出的结论
| AI | 视频号态度 | 抖音态度 |
|----|-----------|----------|
| 豆包 | 最高优先级 | - |
| DeepSeek | 要做，但抖音先放一放 | 精力有限先不做 |
| 元宝 | 要做 | - |
| ChatGPT | 最大机会 | 三个都做 |
| Claude | 第一优先，60-70%精力 | 每天1条 |
| Grok | 第一优先 | - |

### 1.3 关键差异处理
- **DeepSeek说"抖音先放一放"**：因为精力有限，建议先做视频号+小红书
- **其他AI说三个都做**：一次拍摄三版剪辑，成本不高
- **折中方案**：视频号+小红书必做，抖音有时间就做

## 二、三平台分工

| 平台 | 角色 | 精力分配 | 发布频率 |
|------|------|----------|----------|
| 视频号 | 主战场：老客复购+转介绍 | 50% | 每天1条，1-3分钟 |
| 小红书 | 种草搜索：拉新客 | 30% | 每天1条图文 |
| 抖音 | 同城获客 | 20% | 有时间就做，没时间隔天 |

**为什么视频号第一：** 已有微信私域客户，视频号是唯一能激活老客的渠道。

---

## 三、内容生产方式

**一次拍摄，三版剪辑：**
- 每周集中拍一次（2-3小时）
- 产出：1条主视频 + 8-10张照片
- 剪成三个版本发三个平台

## 五、三平台改编方式

### 视频号（主阵地）
- 时长1-3分钟，节奏平稳，老板出镜
- 内容：科普60% + 幕后场景30% + 预告活动10%
- 发布后转发朋友圈+客户群
- 发布时间：12:00 或 20:00

### 小红书
- 图文6-9张，首图带文字标题
- 标题带关键词："翡翠手镯""预算""避坑"
- 自然光真实上手图，不要过度美化
- 发布时间：12:00 或 21:00

### 抖音
- 15-40秒，前3秒强钩子
- 视觉冲击强的单品特写、手电筒光效对比
- 每条加襄阳定位
- 发布时间：12:00 和 18:30

## 六、第一周脚本示例（D5：明码标价）

**前3秒：** "很多人买翡翠最怕的，就是不知道价格怎么算。"

**老板说：**
"尤其是实体店，客户进来第一反应就是：老板，这个是不是可以讲价？"
"所以我们今天直接把价格给大家看。"

**展示货品：**
- 第一件：标价XX，主要是……
- 第二件：这一件XX，跟刚才相比差在……
- 第三件：这一件XX，为什么大小不一样价格差很多

"翡翠价格不能只看大小。最后还是要看具体品质。"
"我觉得实体店做生意，最重要的是你至少要知道自己买的是什么。"

**结尾：** "你们最想看哪个预算？1000、5000、1万还是3万？评论区告诉我。"

## 七、数据测试指标（DeepSeek建议）

30天后统计5种内容类型：
- 避坑类
- 翡翠知识类
- 预算选购类
- 客户案例类
- 老板观点类

**判断标准：**
- 播放高但私信少 → 流量有了，转化有问题
- 播放一般但私信多 → 流量精准，继续做
- 完播率超过50% → 说明那种形式值得继续做
