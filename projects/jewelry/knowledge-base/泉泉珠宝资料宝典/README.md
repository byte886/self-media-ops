## 一、资料概述

本资料宝典是「泉泉珠宝获客」团队近四年小红书珠宝账号运营的总结合集（流量团队 + 线下课上千位珠宝老板在用），内容包含：

- **课程产品**：珠宝小红书特训营（线下课，唯一课程产品，课上绝不升单、绝不推销）
- **见面礼**：洞察报告、答疑手册、合规话术与指南、200 个爆款标题、视频模块（3 个 PDF）
- **重要资料**：5 张内部运营数据统计表（工具表格，用于数据统计与内容优化 SOP）

## 四、重要说明（来源与还原度）

| 项目 | 说明 |
|---|---|
| 文档权限 | 腾讯文档「只能查看」+ 未登录状态，无法直接导出原始文件 |
| 7 个 PDF | 通过预览数据接口下载的**原始文件**，内容完整 |
| 视频框架 PDF | 该文件接口仅返回加密分页块，无完整文件块；采用**预览逐页截图合成**（4 页 PNG → PDF），内容完整可读 |
| 视频框架 MD（09） | 合成 PDF 无文本层，MD 为 **OCR 识别整理**，个别字句可能有识别误差，建议对照 PDF 使用 |
| 5 个表格 | 原始 .xls/.xlsx 导出需登录（403）；经预览确认全部为**空白模板**（仅有表头结构，无数据），已按预览结构**重建等价 .xlsx 模板**，结构一致可直接使用 |
| 表格 MD（10-14） | 记录各表结构（用途/工作表/行列/使用建议），便于查阅复用 |

## 五、使用建议

1. **内容参考**：02~09 的 MD 可直接作为珠宝小红书运营的选题、话术、合规、账号搭建参考手册，按需查阅对应章节。
2. **工具表落地**：将 5 个 xlsx 填入实际运营数据，形成「选题→发布→数据→复盘→优化」的标准化内容生产 SOP。
3. **素材复用**：200 个爆款标题可按分类直接取用/改造；合规话术与指南可复制替换关键信息（地域、品牌、价格）使用。
4. **配套视频**：视频框架 PDF/MD 配合 07（对标拆解）与 08（个人 IP）一起看，覆盖「IP 定位 → 账号对标 → 视频结构」完整链路。
